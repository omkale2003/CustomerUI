# 🌊 KonkanTrip — Customer Travel Booking Experience (Screens 01–10)

An original, production-quality coastal travel booking experience designed specifically for the Konkan coastline (Dapoli, Tarkarli, Ganpatipule, Malvan, Alibaug).

Built with modern semantic HTML5, CSS3 Custom Properties design system, and Vanilla JavaScript with authoritative API simulation.

---

## 🌴 Screen Flow (Screens 01–10)

| Screen | File | Description |
|---|---|---|
| **Screen 01** | `index.html` | **Homepage & Discovery** — Hero search, curated stays, regional coastal collections, seasonal promotions, stories, and verified badges. |
| **Screen 02** | `search.html` | **Destination & Stay Search** — Instant typeahead, smart search badges, popular destinations, regional cards, and recent searches. |
| **Screen 03** | `dates.html` | **Date & Guest Selection** — Dual-month coastal calendar, range selection, minimum stay rules, guest stepper popover, and live stay summary. |
| **Screen 04** | `results.html` | **Search Results / Stay Discovery** — Sticky search summary, dynamic facet filters, horizontal property cards, transparent pricing, and interactive map preview. |
| **Screen 05** | `property.html` | **Property Details** — 5-photo hero gallery, full-screen image viewer, highlights, room cards selection, live sticky pricing, house rules, and verified reviews. |
| **Screen 06** | `booking.html` | **Guest Details & Booking** — Focused checkout header, 5-step progress bar, prefilled customer profile, dynamic guest count, special requests, and price change modal. |
| **Screen 07** | `review.html` | **Review Booking & Confirmation** — 6-step progress indicator, verified stay card, guest summary, price formula breakdown, hold timer, and policy review. |
| **Screen 08** | `payment.html` | **Secure Payment & Checkout** — UPI apps (GPay, PhonePe, Paytm), tokenized card inputs, popular net banking, pay at property, duplicate payment protection, and processing overlay. |
| **Screen 09** | `confirmation.html` | **Booking Confirmation** — Animated success hero, unique booking reference, 3-column stay info, room card, payment summary, status timeline, and printable voucher. |
| **Screen 10** | `booking-details.html` | **My Booking / Booking Details** — Full booking management, breadcrumbs, cancellation modal with live refund calculation, host contacts, 24/7 support, and 10 state handlers. |

## 🚀 How to Run Locally

You can serve the project using any static file server:

### Option 1: Python HTTP Server (Built-in)
```bash
python -m http.server 8080
```
Open [http://localhost:8080/index.html](http://localhost:8080/index.html) in your browser.

### Option 2: Node.js `serve` / `npx http-server`
```bash
npx serve .
# or
npx http-server -p 8080
```
